# Little by Little · 点点滴滴

A person filled with love and curiosity for life — recording observations, 
reflections, thoughts, and experiences gathered along the way. 
Shared with kindred souls who happen to pass by.

> Good writing is not made, but discovered — the gifted hand merely chances upon it.
